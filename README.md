# Учебный интернет-магазин — контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Описание проекта

Многостраничный HTML/CSS-сайт учебного интернет-магазина, разработанный в рамках
контрольной работы №1 по дисциплине «Фронтенд и бэкенд разработка».

## Ссылка на опубликованный проект

GitHub Pages: https://gorachevant-hub.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров с фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — стили проекта с CSS-переменными;
- `js/main.js` — минимальная JavaScript-логика (модальное окно и валидация);
- `images/` — папка для изображений;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, позиционирование);
- БЭМ-именование классов;
- JavaScript (минимальная интерактивность модального окна).

## Реализованные элементы интерфейса

- единая навигация между пятью страницами;
- якорные ссылки на главной странице;
- хлебные крошки на внутренних страницах;
- карточки товаров с БЭМ-модификаторами и бейджами;
- таблица характеристик на странице товара;
- форма заявки с HTML-валидацией;
- модальное окно с формой заявки;
- CSS-переменные, состояния `:hover`, `:focus-visible`;
- Flexbox-навигация и Grid-раскладка карточек;
- sticky-шапка, absolute-бейдж, fixed-кнопка «Наверх».

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Адаптивные решения
- Создан файл `css/responsive.css` и подключён на всех страницах.
- Использован подход Mobile First и медиазапросы.
- Адаптирована навигация (мобильная колонка -> строка на ПК).
- Адаптирована сетка карточек (от 1 до 3 колонок).
- Адаптирована форма заявки (2 колонки на ПК).
- Таблица обёрнута в `.table-wrapper` для прокрутки на мобильных.
- Использованы `srcset` и `sizes` для изображений.

## Доступность (A11y)
- Добавлен `skip-link`.
- Настроен `:focus-visible`.
- Проверены `alt` у картинок и `label` у форм.
- Выполнен аудит Lighthouse (отчёт в папке `lighthouse/`).
