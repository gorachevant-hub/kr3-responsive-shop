
# Учебный интернет-магазин — контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Описание проекта

Многостраничный HTML/CSS-сайт учебного интернет-магазина, разработанный в рамках
контрольной работы №1 по дисциплине «Фронтенд и бэкенд разработка».

## Ссылка на опубликованный проект

GitHub Pages: https://gorachevant-hub.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров с фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — исходные стили проекта с CSS-переменными;
- `css/responsive.css` — адаптивная вёрстка и улучшения доступности;
- `js/main.js` — JavaScript-логика модального окна и валидации;
- `images/` — изображения товаров и фон сайта;
- `lighthouse/` — папка для отчётов проверки;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, позиционирование);
- CSS Media Queries;
- Mobile First;
- БЭМ-именование классов;
- JavaScript (минимальная интерактивность модального окна).

## Реализованные элементы интерфейса

- единая навигация между пятью страницами;
- якорные ссылки на главной странице;
- хлебные крошки на внутренних страницах;
- карточки товаров с БЭМ-модификаторами и бейджами;
- таблица характеристик на странице товара;
- форма заявки с HTML-валидацией;
- модальное окно с формой заявки;
- CSS-переменные, состояния `:hover`, `:focus-visible`;
- Flexbox-навигация и Grid-раскладка карточек;
- sticky-шапка, absolute-бейдж, fixed-кнопка «Наверх».

### Изображения

В папке `images/` находятся:

- `product-1.jpg` — изображение первого товара;
- `product-2.jpg` — изображение второго товара;
- `product-3.jpg` — изображение третьего товара;
- `site-background.png` — фоновое изображение сайта.

Изображения товаров подключены через HTML-тег `img`.

Фон сайта подключён через CSS:

`background-image: url("../images/site-background.png");`

Для адаптации изображений используются `max-width`, `width`, `height`, `aspect-ratio` и `object-fit`.

### Проверка адаптивности

Рекомендуемые размеры экранов:

- 360 px — мобильный телефон;
- 430 px — большой мобильный телефон;
- 768 px — планшет;
- 1024 px — небольшой компьютер;
- 1440 px — широкий экран.

Необходимо проверить отсутствие горизонтальной прокрутки, корректность навигации, карточек, форм и таблицы.

### Lighthouse

Необходимо выполнить проверку Accessibility через Chrome DevTools для страниц:

- `index.html`;
- `catalog.html`;
- `order.html`.

Результаты проверки сохранить в папку `lighthouse/`.
